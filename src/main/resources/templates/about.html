About

Built for campus event teams.

EventSphere is a Spring Boot and Thymeleaf platform for college event operations: publishing events, registering students, marking attendance, collecting feedback, and issuing certificates.

Admin

Govern access

Manage user status and assign student, organizer, volunteer, or admin roles.

Organizer

Run events

Create and publish events, review registrations, and track attendance.

Student

Participate

Browse events, register, submit feedback, and download certificates.
